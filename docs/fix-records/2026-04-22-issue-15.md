## Issue #15：TestCase.title 禁止以数字开头，但 LLM 经常生成这样的标题

### 问题描述

`TestCase` 的 title 验证器禁止标题以数字开头：

```python
# 修复前（不合理的限制）
@field_validator('title')
@classmethod
def validate_title_format(cls, v):
    # 确保标题不以数字开头，不包含特殊字符
    if v[0].isdigit():
        raise ValueError("测试用例标题不能以数字开头")
    ...
```

但 LLM 生成的标题经常是 `"1. 验证用户登录成功"` 或 `"TC001 正常登录流程"` 这样的格式，导致验证失败触发降级，生成质量下降。

这个限制没有实际业务意义。

### 修复方案

移除这个不合理的限制，只保留真正有意义的验证（文件系统不允许的字符）：

```python
# 修复后（只过滤真正有问题的字符）
@field_validator('title')
@classmethod
def validate_title_format(cls, v):
    v = v.strip()
    # 只过滤文件系统不允许的字符（用于生成测试文件名）
    invalid_chars = ['<', '>', '|', '*', '?', '"', '\n', '\r']
    for char in invalid_chars:
        if char in v:
            raise ValueError(f"测试用例标题不能包含字符: {char}")
    return v
```

3. **添加 `\n`, `\r` 限制** — 防止换行符破坏文件格式
4. **添加 `v.strip()`** — 自动去除前后空格
