## Issue #24：requirements.txt 缺少关键依赖，且版本固定策略不一致

### 问题描述

`requirements.txt` 存在多个问题：

**1. 缺少已使用的依赖：**
```
langgraph          # workflow.py 中 from langgraph.graph import StateGraph
```

**2. 列出了未使用的依赖：**
```
PyMuPDF==1.24.0    # 代码中从未 import
python-docx==1.1.0 # 同上，从未使用
markdown==3.7      # 同上，从未使用
```

**3. 版本固定过死，升级困难：**
```
openai==1.12.0     # 固定到小版本，安全补丁无法自动获取
langchain==0.3.13  # 同上
```

### 修复方案

1. **补充缺失依赖** — 添加 `langgraph>=0.2.0,<0.3.0`
2. **移除未使用依赖** — 删除 PyMuPDF、python-docx、markdown
3. **放宽版本限制** — 使用 `>=x.y.z,<x+1.0.0` 格式，允许次版本升级

### 修改文件

| 文件 | 修改内容 |
|------|----------|
| `requirements.txt` | 补充 langgraph，移除未使用依赖，放宽版本限制 |
