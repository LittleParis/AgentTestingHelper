## Issue #27：conftest.py 中 OUTPUT_DIR 被重复定义，覆盖了导入的值

### 问题描述

`tests/conftest.py` 中存在变量遮蔽（shadowing）问题：

```python
# 第1行：从 project_paths 导入
from core.utils.project_paths import OUTPUT_DIR, GENERATED_TESTS_DIR

# 第N行：又重新赋值，覆盖了导入的值！
PROJECT_ROOT = Path(__file__).parent.parent
OUTPUT_DIR = PROJECT_ROOT / OUTPUT_DIR          # ← 用绝对路径覆盖了相对路径
GENERATED_TESTS_DIR = PROJECT_ROOT / GENERATED_TESTS_DIR  # ← 同上
```

这会导致：
- `project_paths.py` 中的路径是相对路径（`Path("output")`）
- `conftest.py` 中变成了绝对路径（`/path/to/project/output`）
- 两处路径不一致，可能导致清理操作作用在错误的目录

### 影响链路分析

**受影响的执行链路：**
1. **测试清理链路** — `clean_old_files()` 可能操作错误的目录
2. **测试输出链路** — 生成的测试结果文件可能写入错误位置
3. **Allure 报告链路** — 报告生成时找不到正确的输出目录

**影响范围：** 模块级（影响所有使用 OUTPUT_DIR 的测试）

### 修复方案

在 `project_paths.py` 中统一提供绝对路径，`conftest.py` 直接使用，不再重新赋值：

```python
# project_paths.py
PROJECT_ROOT = Path(__file__).parent.parent.parent  # 项目根目录
OUTPUT_DIR = PROJECT_ROOT / "output"  # 绝对路径
```

### 修改文件

| 文件 | 修改内容 |
|------|----------|
| `core/utils/project_paths.py` | 添加 PROJECT_ROOT，所有路径改为绝对路径 |
| `tests/conftest.py` | 移除重复的路径拼接代码 |

### 涉及方法说明

| 方法名 | 所在文件 | 作用说明 |
|--------|----------|----------|
| `ensure_runtime_directories()` | `project_paths.py` | 确保运行期需要的目录存在，创建缺失的目录 |
| `clean_old_files()` | `conftest.py` | 清理历史文件，只保留最新的 N 个版本 |
| `clean_output` | `conftest.py` | pytest fixture，清理 output 目录的历史文件 |

**示例：**
```python
# project_paths.py 导出绝对路径
from core.utils.project_paths import OUTPUT_DIR, PROJECT_ROOT

# OUTPUT_DIR 现在是绝对路径
print(OUTPUT_DIR)  # G:\桌面\AgentTest\output

# conftest.py 直接使用，无需再拼接
from core.utils.project_paths import OUTPUT_DIR, GENERATED_TESTS_DIR

# 清理函数直接使用
clean_old_files(OUTPUT_DIR, keep_latest=1)
```

配置文件修复，无需单元测试。运行现有测试验证：

