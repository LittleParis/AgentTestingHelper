## Issue #28：package.json 和 playwright.config.ts 放在 config/ 子目录，导致 npx 命令找不到配置

### 问题描述

`package.json` 和 `playwright.config.ts` 都放在 `config/` 子目录下，但 `TestExecutor` 在项目根目录执行 `npx playwright test`：

```python
# test_executor.py
result = subprocess.run(
    ["npx", "playwright", "test", script_path, ...],
    # 没有指定 --config，默认在当前目录查找 playwright.config.ts
)
```

Playwright 默认在当前目录查找 `playwright.config.ts`，但配置文件在 `config/playwright.config.ts`，所以：
- Playwright 找不到配置文件，使用默认配置
- `package.json` 在 `config/` 目录意味着 `node_modules` 安装在 `config/node_modules/`

### 影响链路分析

**受影响的执行链路：**
1. **测试执行链路** — `TestExecutor.run_tests()` 找不到 Playwright 配置，使用默认配置
2. **Allure 报告链路** — allure-results 路径错误，报告生成失败
3. **浏览器启动链路** — 浏览器路径配置不生效

**影响范围：** 模块级（影响所有 UI 自动化测试执行）

### 修复方案

在 `TestExecutor._build_playwright_command_args()` 中添加 `--config` 参数，明确指定配置文件路径：

```python
# 修复后
config_path = Path(project_root) / "config" / "playwright.config.ts"
parts = [
    npx_executable, "playwright", "test", script_path,
    f"--config={config_path.as_posix()}",
    ...
]
```

同时更新 `playwright.config.ts` 中的相对路径（因为配置文件在 `config/` 子目录）：
- `testDir`: `./midscene_run/generated` → `../midscene_run/generated`
- `browsers`: `__dirname/browsers` → `__dirname/../browsers`
- `allure-results`: `./allure-results` → `../allure-results`

### 修改文件

| 文件 | 修改内容 |
