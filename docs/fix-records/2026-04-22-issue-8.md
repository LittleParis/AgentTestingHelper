## Issue #8：MidsceneScriptGenerator action 转换逻辑脆弱

### 问题描述

`_convert_action_to_ai_prompt()` 和 `_convert_expected_to_ai_prompt()` 使用大量硬编码的关键词匹配来转换测试步骤，这是整个项目最脆弱的部分：

```python
# 修复前（脆弱的硬编码匹配）
if "输入" in action or "填写" in action:
    if "邮箱" in action or "用户名" in action:
        return f'在邮箱或用户名输入框中输入 "{data}"'
    elif "密码" in action:
        return f'在密码输入框中输入 "{data}"'
    elif "搜索" in action or "关键词" in action:
        ...
# 遇到"请在搜索栏键入内容"这类描述就完全失效
```

同时 `_generate_decorators()` 方法生成的是 Python pytest 装饰器，但脚本是 TypeScript，这个方法从未被调用，是死代码。

### 修复方案

**方案 A（短期）**：把 action 转换交给 LLM 处理，而不是规则匹配：

```python
# 修复后（LLM 批量转换）
class ActionConversionResult(BaseModel):
    """LLM 返回的 action 转换结果"""
    steps: List[Dict[str, str]] = Field(
        default_factory=list,
        description="转换后的步骤列表"
    )

def _convert_steps_with_llm(self, steps: List[Dict]) -> List[Dict]:
    """使用 LLM 批量转换测试步骤为 Midscene AI 指令"""
    structured_llm = self.llm_client.with_structured_output(ActionConversionResult)
```

**清理死代码**：删除 `_generate_decorators()` 方法。
