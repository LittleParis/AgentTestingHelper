## Issue #9：TestExecutor 输出解析用正则匹配，不稳定

### 问题描述

`parse_playwright_output()` 用正则表达式解析 Playwright CLI 的文本输出来统计测试结果，这非常脆弱：

- Playwright 版本升级后输出格式变化会导致解析失败
- 文件中有两段重复的汇总解析代码（第二段是死代码，`return` 之后的代码永远不会执行）
- 中文路径、特殊字符可能导致正则匹配失败

```python
# 修复前（脆弱的正则匹配）
summary_passed = re.search(r"(\d+)\s+passed", output)

# 文件中存在死代码（return 之后还有代码）
results["total"] = results["passed"] + results["failed"] + results["skipped"]
return results  # ← 这里已经 return 了

# 下面这段永远不会执行
summary_passed = re.search(r"(\d+)\s+passed", output)  # 死代码
```

### 修复方案

使用 Playwright 的 JSON reporter 替代文本解析：

```python
# 修复后（使用 JSON reporter）
cmd_list = self._build_playwright_command_args(script_path, json_report_path)
# 包含 --reporter=json --output={json_report_path}

# 直接解析 JSON，稳定可靠
with open(json_report_path) as f:
    report = json.load(f)
    passed = report["stats"]["expected"]
    failed = report["stats"]["unexpected"] + report["stats"]["flaky"]
```

同时：
- 清理死代码（return 之后的代码已删除）
- 保留文本解析作为降级方案 `_parse_text_output_fallback()`
- 递归提取测试用例信息 `_extract_tests_from_suite()`
