# Issue #26：generate_allure_from_results.py 移除硬编码

## 问题描述

`scripts/generate_allure_from_results.py` 硬编码了错误信息和测试名称：

```python
# 硬编码的错误信息（来自某次具体的运行）
error_message = "failed to call AI model service: 400 Access denied, please make sure your account is in good standing"

# 硬编码的默认测试名称（百度搜索相关）
if not failed_tests:
    failed_tests = [
        "TC_001: 验证使用有效关键词进行搜索并成功跳转",
        "TC_002: 验证搜索框为空时点击搜索按钮的处理",
        "TC_003: 验证搜索特殊字符关键词"
    ]

# 硬编码的执行时间
duration=2.5 + i * 0.2  # 模拟不同的执行时间
```

这意味着无论实际运行什么测试，降级报告永远显示"百度搜索"的测试名称和同一个错误信息。

## 影响链路分析

- **脚本文件**: `scripts/generate_allure_from_results.py`
- **影响范围**: 当 Playwright 测试失败且未生成 allure 结果时，使用此脚本生成的报告数据不准确
- **影响链路**: 测试执行 → 执行失败 → 降级生成 Allure 数据 → 报告显示错误信息

## 修复内容

### 1. 测试名称：从测试用例文件读取

```python
# 如果没有解析到具体测试，从测试用例文件读取
if not failed_tests:
    test_cases_files = list(output_dir.glob("test_cases*.json"))
    if test_cases_files:
        latest_tc_file = max(test_cases_files, key=lambda p: p.stat().st_mtime)
        with open(latest_tc_file, 'r', encoding='utf-8') as f:
            tc_data = json.load(f)
        for tc in tc_data.get("test_cases", []):
            tc_id = tc.get("id", "TC_XXX")
            tc_title = tc.get("title", "未命名测试")
            failed_tests.append(f"{tc_id}: {tc_title}")
```

### 2. 错误信息：从执行结果提取

```python
# 从执行结果中提取错误信息
error_message = execution_data.get("error", "")
if not error_message:
    error_message = execution_data.get("stderr", "")
if not error_message:
    # 尝试从 raw_output 中提取错误
    raw_output = execution_data.get("raw_output", "")
    if "Error:" in raw_output:
        for line in raw_output.split('\n'):
            if "Error:" in line:
                error_message = line.strip()
                break
if not error_message:
    error_message = "测试执行失败，请查看详细日志"
```

### 3. 执行时间：使用实际数据

```python
# 获取实际执行时间（如果有）
execution_time = execution_data.get("execution_time", 0)

# 使用实际执行时间或按测试数量均分
if execution_time and execution_time > 0:
    duration = execution_time / max(len(failed_tests), 1)
else:
    duration = 2.5 + i * 0.2  # 降级方案
```

## 涉及方法说明

| 方法/字段 | 说明 |
|-----------|------|
| `execution_data.get("error")` | 从执行结果 JSON 读取错误信息 |
| `execution_data.get("stderr")` | 从标准错误输出读取错误 |
| `execution_data.get("execution_time")` | 从执行结果读取总耗时 |
| `test_cases*.json` | 测试用例输出文件，包含实际生成的测试名称 |

## 修改文件

- `scripts/generate_allure_from_results.py` — 移除所有硬编码，改为从实际文件读取
