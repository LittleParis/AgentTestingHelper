# Issue #32：pytest.ini 移动到根目录并更新配置

## 问题描述

`config/pytest.ini` 存在两个问题：

1. **位置错误**：pytest 默认在项目根目录查找 `pytest.ini`，放在 `config/` 子目录导致配置不生效
2. **testpaths 不精确**：配置为 `tests`，但实际测试文件分布在 `tests/unit/` 和 `tests/integration/`

```ini
# 修复前
[pytest]
testpaths =
    tests
addopts =
    --alluredir=allure-results  # 每次 pytest 都会清空 allure 结果
    --clean-alluredir
```

## 影响链路分析

- **配置文件**: `config/pytest.ini` → 移动到 `pytest.ini`
- **影响范围**: 所有 pytest 测试运行
- **影响链路**: 
  - pytest 无法自动加载配置 → 需要手动指定 `-c config/pytest.ini`
  - allure 结果被意外清空 → 与 Playwright 生成的 allure 结果冲突

## 修复内容

### 1. 移动文件到根目录

```bash
mv config/pytest.ini pytest.ini
```

### 2. 更新配置

```ini
[pytest]
asyncio_mode = auto
testpaths =
    tests/unit
    tests/integration
python_files = test_*.py
python_classes = Test*
python_functions = test_*

addopts =
    -v
    --tb=short

markers =
    smoke: 冒烟测试
    regression: 回归测试
    slow: 慢速测试
```

### 修改说明

| 配置项 | 修改前 | 修改后 |
|--------|--------|--------|
| 文件位置 | `config/pytest.ini` | `pytest.ini`（根目录） |
| testpaths | `tests` | `tests/unit` `tests/integration` |
| addopts | 包含 `--alluredir` | 移除 allure 相关配置 |

**移除 allure 配置的原因**：
- Playwright 测试有自己的 allure 输出配置
- 每次 pytest 运行都清空 allure-results 会影响其他测试的结果

## 涉及方法说明

| 配置项 | 说明 |
|--------|------|
| `testpaths` | 指定 pytest 发现测试的目录 |
| `asyncio_mode = auto` | 自动处理 async 测试函数 |
| `addopts` | 默认命令行参数 |

## 验证结果

```
configfile: pytest.ini
testpaths: tests/unit, tests/integration
...
======================= 20 passed in 0.67s ========================
```

## 修改文件

- `config/pytest.ini` → 移动到 `pytest.ini`
- `pytest.ini` — 更新 testpaths 和 addopts
