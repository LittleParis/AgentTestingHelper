# Issue #37：QUICKSTART.md 环境变量名称错误

## 问题描述

`docs/QUICKSTART.md` 中的配置说明使用了错误的环境变量名和路径：

```markdown
# 错误的环境变量名
ANTHROPIC_API_KEY=sk-ant-xxxxx  # 应该是 LLM_KEY

# 错误的虚拟环境目录
python -m venv venv  # 项目实际使用 .venv

# 错误的入口文件
python main.py  # 项目推荐使用 main_v2.py
```

## 影响链路分析

- **文档文件**: `docs/QUICKSTART.md`
- **影响范围**: 新用户快速启动指南
- **影响链路**: 用户阅读文档 → 配置错误 → 启动失败

## 修复内容

### 1. 环境变量名称

```markdown
# 修复前
ANTHROPIC_API_KEY=sk-ant-xxxxx

# 修复后
LLM_KEY=your_api_key_here
LLM_MODEL=gpt-3.5-turbo
```

### 2. 虚拟环境目录

```markdown
# 修复前
python -m venv venv
.\venv\Scripts\Activate.ps1

# 修复后
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. 入口文件

```markdown
# 修复前
python main.py

# 修复后
python main_v2.py
```

### 4. 测试脚本路径

```markdown
# 修复前
tests/generated/tc_001.py

# 修复后
midscene_run/generated/*.spec.ts
```

### 5. 错误提示信息

```markdown
# 修复前
Q: 提示 "ANTHROPIC_API_KEY not found"

# 修复后
Q: 提示 "LLM_KEY 未配置"
```

## 修改文件

- `docs/QUICKSTART.md` — 修正环境变量名、虚拟环境目录、入口文件、测试路径
