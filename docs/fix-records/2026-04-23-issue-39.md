# Issue #39：llm_api_key 默认空字符串不报错

## 问题描述

`ProjectSettings.llm_api_key` 默认值为空字符串：

```python
llm_api_key: str = Field(
    default="",  # 默认空字符串
    validation_alias=AliasChoices('llm_api_key', 'LLM_KEY'),
)
```

这导致：
- 用户忘记配置 `.env` 时，程序不会在启动时报错
- 直到第一次调用 LLM 时才会失败（浪费时间）
- 错误信息不明确，难以定位问题

## 影响链路分析

- **配置文件**: `core/models/config.py`
- **影响范围**: 所有依赖 `get_settings()` 的模块
- **影响链路**: 启动 → 加载配置 → 调用 LLM → 失败

## 修复内容

在 `get_settings()` 中添加启动时检查：

```python
def get_settings() -> ProjectSettings:
    """获取项目配置实例（单例模式）"""
    global _settings_instance
    if _settings_instance is None:
        _settings_instance = ProjectSettings()
        # 启动时检查关键配置
        if not _settings_instance.llm_api_key:
            raise ValueError(
                "LLM_KEY 未配置，请在 .env 文件中设置：\n"
                "  LLM_KEY=your_api_key_here\n"
                "  LLM_MODEL=gpt-3.5-turbo"
            )
    return _settings_instance
```

## 涉及方法说明

| 方法 | 说明 |
|------|------|
| `get_settings()` | 获取项目配置单例，现在会检查 LLM_KEY |
| `ProjectSettings.llm_api_key` | LLM API 密钥，从 `.env` 的 `LLM_KEY` 读取 |

## 验证结果

**未配置 LLM_KEY 时：**
```
ValueError: LLM_KEY 未配置，请在 .env 文件中设置：
  LLM_KEY=your_api_key_here
  LLM_MODEL=gpt-3.5-turbo
```

**已配置 LLM_KEY 时：**
```
LLM_KEY 已配置: True
LLM_MODEL: astron-code-latest
```
