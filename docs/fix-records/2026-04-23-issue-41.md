# Issue #41：test_workflow.py import 路径修复

## 问题描述

`tests/integration/test_workflow.py` 中的 Mock 装饰器使用了旧的导入路径（缺少 `core.` 前缀），导致测试无法正确 Mock 目标类：

```python
# 错误的旧路径
@patch("agents.workflow.RequirementAnalyzer")   # ❌
@patch("agents.workflow.TestCaseGenerator")     # ❌
```

这意味着这些测试的 Mock 从未生效，测试实际上调用了真实的 Agent 类。

## 影响链路分析

- **测试文件**: `tests/integration/test_workflow.py`
- **影响范围**: 4 个测试方法中的 Mock 装饰器
  - `TestAnalyzeRequirementsNode::test_analyze_success`
  - `TestGenerateTestCasesNode::test_generate_success`
  - `TestWorkflowIntegration::test_run_workflow_success`

## 修复内容

将 Mock 路径从 `agents.workflow.XXX` 改为 `core.agents.workflow.XXX`：

```python
# 修复后的正确路径
@patch("core.agents.workflow.RequirementAnalyzer")   # ✅
@patch("core.agents.workflow.TestCaseGenerator")     # ✅
```

## 涉及方法说明

- `@patch("module.path.ClassName")`: unittest.mock 装饰器，用于替换指定路径的类
- 路径必须是模块被 `import` 时的实际路径，而非文件系统路径
