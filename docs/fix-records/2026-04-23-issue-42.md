# Issue #42：test_analyzer_core.py 改写为标准 pytest 格式

## 问题描述

`tests/unit/test_analyzer_core.py` 使用自定义测试框架，不符合 pytest 规范：

```python
# 原来的问题
def test_core_functionality():
    print("✅ 返回类型: ...")
    return True  # pytest 不看返回值

if __name__ == "__main__":
    for test_name, test_func in tests:
        if test_func():  # pytest 不这样调用
            passed += 1
```

这导致：
- pytest 无法正确识别测试结果
- 没有 `assert` 语句，测试永远"通过"
- 无法与 CI/CD 集成

## 影响链路分析

- **测试文件**: `tests/unit/test_analyzer_core.py`
- **影响范围**: 需求分析核心功能的测试
- **影响链路**: pytest 收集 → 无法正确判断测试结果 → CI/CD 无法检测失败

## 修复内容

改写为标准 pytest 格式：

```python
import pytest

class TestRequirementAnalyzerCore:
    """测试需求分析Agent核心功能"""

    @pytest.fixture
    def analyzer(self):
        return RequirementAnalyzerCore()

    def test_analyze_structured_returns_pydantic_model(self, analyzer, valid_requirement):
        result = analyzer.analyze_structured(valid_requirement)
        assert isinstance(result, RequirementAnalysisResult)
        assert result.total_count == 1

    def test_empty_input_raises_error(self, analyzer):
        with pytest.raises(ValueError, match="至少需要10个字符"):
            analyzer.analyze_structured("")
```

## 涉及方法说明

| pytest 特性 | 说明 |
|-------------|------|
| `@pytest.fixture` | 测试夹具，提供共享的测试数据或对象 |
| `assert` | 断言，pytest 通过断言判断测试是否通过 |
| `pytest.raises` | 测试期望抛出的异常 |
