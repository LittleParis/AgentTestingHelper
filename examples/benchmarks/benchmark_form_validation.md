# Form Validation Benchmark

## Page URL
https://example.com/signup

## Goal
Verify that invalid form input is rejected with clear inline validation feedback.

## Acceptance Criteria
1. The registration form can be opened from the landing page.
2. Submitting an invalid email format shows a visible validation message.
3. Leaving a required password field empty blocks submission.
4. No success state is shown when validation fails.

## Suggested Focus
- Negative form scenarios
- Clear expected assertions
- Stable field-level validation checks
