# List Search Benchmark

## Page URL
https://www.baidu.com

## Goal
Verify that a query can be entered and the results page clearly reflects the search request.

## Acceptance Criteria
1. The search input is visible on page load.
2. Entering a query and submitting it navigates to a result page.
3. The result page shows the submitted query in a visible result context.
4. The test uses stable result assertions instead of vague "page looks correct" wording.

## Suggested Focus
- Search field interaction
- URL/result assertions
- Deterministic post-submit checks
