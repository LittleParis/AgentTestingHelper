# 用户登录功能需求

## 功能描述
用户应该能够使用邮箱和密码登录系统。登录成功后跳转到首页，显示用户信息。

## 详细需求

### 登录表单
- 页面包含邮箱输入框
- 页面包含密码输入框
- 页面包含"登录"按钮
- 页面包含"忘记密码"链接

### 验证规则
- 邮箱格式必须正确（包含@符号）
- 密码长度至少6位
- 两个字段都是必填项

### 成功场景
- 用户输入正确的邮箱和密码
- 点击登录按钮
- 系统验证通过
- 跳转到首页
- 右上角显示用户邮箱

### 失败场景
- 邮箱格式错误：显示"请输入有效的邮箱地址"
- 密码错误：显示"邮箱或密码错误"
- 空字段：显示"请填写所有必填项"
- 账号不存在：显示"账号不存在"

## 优先级
高优先级（P0）

## 验收标准
1. 正确的凭证能够成功登录
2. 错误的凭证显示相应错误提示
3. 表单验证正常工作
4. 登录状态正确保持
